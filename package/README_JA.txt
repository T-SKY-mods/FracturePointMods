Fracture Point ファン MOD セット 1.1.1
==========================================

対応ゲーム : Steam ビルド 25787540 ／ MOD ローダー: MelonLoader 0.7.3
英語版     : README.txt

  Install.bat                         すべての MOD をまとめて入れる
  Uninstall.bat                       すべての MOD を外す（MelonLoader は残す）
  Uninstall (also MelonLoader).bat    すべての MOD と MelonLoader を外す（完全にバニラ）
  Mods\ UserData\                     MOD 本体とモデル（Install.bat が使います）
  Docs\Weapon_Stats.xlsx              全武器・全レアリティの性能表
  Source\                             MOD のソースコード


0. はじめに（使い方の流れ）
---------------------------
  1. 「Install.bat」で、すべての MOD を一度ゲームに入れます（MOD ごとに選んで入れることはできません）
  2. ゲームを起動すると、最初はすべての MOD がオンです
  3. タイトル画面の「設定」>「MOD」タブで、いらない MOD をオフにして、お好みのスタイルで遊んでください
     - レアリティmod は、レアリティ・武器熟練度・ボスフロアを機能ごとにもオン／オフできます
     - オン／オフは、ゲームを再起動すると反映されます
     - どの MOD も単独で動きます（たとえば「サバイバルモードだけ」「最適化だけ」でも遊べます）
     - オフにしても、その MOD のデータ（武器のレアリティ・熟練度・アタッチメント・サバイバルの記録）は消えません。
       オンに戻すと、すぐに元どおりになります


1. MOD の内容（おおまかに）
---------------------------
  [レアリティmod]（FPRarity）
    - 拾った武器 1 本ごとに、レアリティ（コモン〜レジェンダリー）と性能（ダメージ・連射速度・
      コントロール・エルゴ）が付きます。深い階ほど高レアが出やすくなります
      落ちている武器の種類は、どの階でも全武器が同じ確率で出ます
      コントロール +1 で反動 約 -3%、エルゴ +1 で構える速さ +1% です
      エルゴ・コントロールの数値は、実際の構える速さと反動から計算して表示します（同じ数値なら同じ性能）
    - 武器熟練度（Lv1〜100）。キルで上がり、10 レベルごとの強化ポイントで武器を強くできます（振り直し自由）
    - エンドレスモードの階が、ときどきボス部屋になります（10 階ごとに強くなります）
    - 性能はゲーム本来の性能カードやツールチップに出ます。性能表は Docs\Weapon_Stats.xlsx

  [サバイバルモードmod]（FPSurvival）
    - 屋上で、終わりのない敵のウェーブと戦い続けるエンドコンテンツです
    - 拠点のエンドレスモードの端末で「サバイバル ▶」から始めます。休憩中に非常口から脱出すると、
      稼いだお金・武器箱の武器・敵が落とした壊れた武器部品を持ち帰れます。
      倒れても持ち込んだ物は失いません（その回に拾った物と稼いだお金はなくなります）
    - レアリティmod がオンなら、武器箱の武器に到達ウェーブに応じたレアリティが付きます
    - 持ち込む装備を絞るほど、武器箱から良い報酬が出やすくなります

  [武器カスタマイズmod]（FPCustom）
    - 保管庫の「カスタマイズ」ページで、武器にアタッチメントを付け外しできます
      ライフル・SMG・ショットガン: 20 種類（マズル 5・グリップ 5・サイト 5・レーザー 3・マガジン 2）
      ハンドガン: 12 種類（マズル 5・ストック 1・サイト 1・レーザー 3・マガジン 2）
    - 解放には「壊れた武器部品」が必要です（武器の種類ごと）
    - アタッチメントごとに、反動・エルゴ・リロードなどの性能が変わります
    - スライディングの調整
        全武器    : スライディング中は、敵の弾を 70% の確率で受けません
        メイン武器: スライディング中はエイムできません（腰だめ射撃はできます）
        ハンドガン: 約 5m 滑り、硬直なしでそのまま走れます。滑りながら・走りながらエイム射撃でき、移動速度 +5%
      アングルフォアグリップを付けたメイン武器はハンドガンと同じ動きに、M93R ストックを付けたハンドガンはメイン武器と同じ動きになります
    - レアリティmod がオンなら、熟練度ページとカスタマイズページを行き来できます

  [最適化mod]（FPOptimize）
    - 見た目と操作を変えずに、CPU の無駄な処理を減らして、カクつきと敵が多い場面の FPS 低下を軽くします

  [MOD 設定]（FPModOption）
    - すべての MOD が使う共通の部品と、設定画面の「MOD」タブです。オフにはできません
    - MOD を入れている間は、リーダーボードに送信しません（オンラインのランキングに影響しません）


2. 入れ方
---------
  1. ゲームをメニューから終了します
  2. zip をすべて展開し、「Install.bat」をダブルクリックします。次の作業は自動で行います
     - ゲームのフォルダを Steam のライブラリから自動で探します。見つからなければ場所を聞かれるので、
       「Fracture Point Release.exe」があるフォルダを入力してください
     - セーブ（LocalLow のフォルダとレジストリ）と MOD のデータを ドキュメント\FPMods_backup\<日時> にバックアップします
     - MelonLoader 0.7.3 が入っていなければ、公式 GitHub から入れます（SHA256 でファイルを確認。インターネット接続が必要です）
     - すべての MOD を入れます
  3. Steam からゲームを起動します（MelonLoader を入れた最初の起動は数分かかります）
  4. 「設定」>「MOD」で、いらない MOD をオフにしてから、ゲームを再起動します

  「Windows によって PC が保護されました」と出たら、「詳細情報」>「実行」を押してください。
  前のバージョン（FPRarity・FPSurvival・FPOptimize を別々に入れていた場合も）の上から、そのまま入れられます。
  MOD のデータと、「設定」>「MOD」のオン/オフはそのまま残ります。
  初めて入れたとき（Uninstall.bat で外したあとに入れ直したときも）は、すべての MOD がオンで始まります。


3. 外し方（アンインストール）
-----------------------------
  一部の MOD だけやめたいとき
    「設定」>「MOD」でオフにして、ゲームを再起動してください（ファイルを消す必要はありません）

  Uninstall.bat
    すべての MOD を外します。MOD のデータと MelonLoader は残します。
    「設定」>「MOD」のオン/オフは消すので、入れ直すとすべてオンから始まります。
    「Install.bat」で、すぐに元に戻せます

  Uninstall (also MelonLoader).bat
    MelonLoader も外して、完全にバニラに戻します。
    次のときは MelonLoader を残します（ほかの MOD を壊さないため）
      - ほかの MOD やプラグインが Mods・Plugins フォルダに残っている
      - MelonLoader が、この MOD を入れる前から入っていた（Install.bat が入れたものではない）
    MelonLoader はこのゲームのフォルダの中にだけ入るので、ほかのゲームには影響しません

  どちらのバッチも、ゲームのセーブは変更しません。MOD のデータ（UserData の中）も残るので、
  あとで「Install.bat」で入れ直すと、レアリティ・熟練度・アタッチメントなどはそのまま戻ります。

  外している間の武器など
    - レアリティの付いた武器は、そのまま使えます。性能とレアリティの表示はバニラに戻ります
      （レアリティは MOD のデータに残っていて、入れ直すと戻ります）
    - 拡張マガジンは元の大きさになり、多い分の弾は外している間は使えません
    - アタッチメントは付いていない見た目・性能になります（入れ直すと戻ります）
    - 壊れた武器部品はゲームの普通のアイテムなので、そのまま残ります
  サバイバルの途中でゲームを終えて、預かり品がまだ返っていないときは、外すバッチは止まります。
  サバイバルモードmod をオンにして起動し、拠点に入って預かり品を受け取ってから外してください。

  手動で外す場合
    <ゲームフォルダ>\Mods\ から FPModOption.dll・FPRarity.dll・FPSurvival.dll・FPCustom.dll・FPOptimize.dll を消します。
    （任意）<ゲームフォルダ>\UserData\ の FPModOption・FPRarity・FPSurvival・FPCustom・FPOptimize フォルダも消します。
    これを消すと、MOD のデータ（レアリティ・熟練度・アタッチメント・サバイバルの記録・設定）もなくなります


4. ゲームがアップデートされたとき
---------------------------------
  - MOD は、起動するたびにゲームのビルドを確かめます
    - 未検証のビルド: MOD は動きますが、拠点で「MOD: 未検証のゲームバージョンで動作中」と出ます
    - 一部の機能が合わなくなった: その機能だけ止まり、拠点で通知が出ます
    - 大事な部分（リーダーボードの送信停止など）が合わなくなった: すべての MOD が自動で止まり、
      バニラとして動きます（「MOD: ゲーム更新に未対応のため無効化中」）。MOD のデータはそのまま残ります
  - ゲームのビルドが変わると、MOD のデータファイルを自動でバックアップします
  - ゲームが起動しない・すぐ落ちるとき
    1. 「Uninstall (also MelonLoader).bat」で MOD と MelonLoader を外します（データは残ります）
    2. それでも直らなければ、Steam の「ゲームファイルの整合性を確認」をします
    3. 新しいゲームに対応した MOD が出たら、その「Install.bat」で入れ直します（データは戻ります）
  - アップデートの直後は、念のため MOD を外して遊ぶか、対応版が出るまで待つのがおすすめです


5. 注意
-------
  - 入れる・外すとき、MOD のオン／オフを切り替えたあとは、ゲームを終了しておいてください（再起動で反映）
  - ゲームは必ずメニューから終了してください
  - MOD を入れた状態で起きたバグは、ゲームの開発者に報告しないでください。
    MOD を外して同じことが起きるか確かめてから報告してください
  - MOD をオフにしていた間に手に入れた武器は、オンに戻すとゲーム本来の性能のままです
    （オフの間に倉庫と手持ちを入れ替えただけの武器は、レアリティが戻ります）
  - 武器カスタマイズmod をオフにすると、アタッチメントの見た目と効果、スライディングの調整がなくなります
    （解放と装着の記録は残ります）。拡張マガジンで増えた分の弾は消えます
  - サバイバルモードmod をオフにしても、途中でやめた回の預かり品は消えません。オンに戻して拠点に入ると返ります


6. 困ったとき
-------------
  - セーブのバックアップは ドキュメント\FPMods_backup\<日時> にあります。
    LocalLow のフォルダと PlayerPrefs.reg は、両方いっしょに戻してください
  - ログ: <ゲームフォルダ>\UserData\FPModOption\fpmod.log（最適化mod は UserData\FPOptimize\fpoptimize.log）
  - ゲーム本体のファイルは、Steam の「ゲームファイルの整合性を確認」で元に戻せます


7. クレジット
-------------
  - MOD: ファンプロジェクト（AI［Claude］の支援で作成）
  - 3D モデル（Sketchfab の無料モデル、CC BY 4.0、改変あり）。作者とリンクは次のファイルにあります
      UserData\FPRarity\models\CREDITS.txt（サイトのレール・マウント）
      UserData\FPCustom\models\CREDITS.txt（ハンドガード・マズル・グリップ・バイポッド）
  - 一部のモデルは、ゲームのモデルを加工したものです
  - そのほかのサイト・アタッチメント・武器は、ゲーム自身の素材を使っています
